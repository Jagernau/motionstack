Настоящие фазы движения • автовыделение по касанию • офлайн

1. Видео и интервал

Всё обрабатывается только на устройстве. Видео никуда не отправляется.

2. Нажми на спортсмена

В APK v0.2: выбери кадр и один раз нажми на человека (лучше по центру туловища). Модель MagicTouch автоматически определит контур на всех кадрах. Для маленьких фигур в толпе попробуй уменьшить область анализа или перезапустить с другого кадра. Ручная обводка осталась на случай ошибок.

Кадр

Режим ✨: нажми на торс спортсмена; программа обработает все выбранные кадры автоматически. Затем проверь каждый силуэт. В режиме «Вручную» проведи по контуру. «Перемещать» используется при увеличении. AI работает в APK, для Termux остаётся ручной режим.

3. Результат

На одном фоне совмещаются реальные фазы из видео, выбранные моделью или вручную. Можно удалить неверное выделение, выбрать другую фазу и нажать заново.

В режиме «Автофон» используется медиана трёх реальных кадров, чтобы приглушить движущиеся объекты. Она не гарантирует полного удаления человека и может оставлять артефакты при большом движении камеры. Для точного результата нужна неподвижная камера.
