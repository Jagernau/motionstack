## ✨ Что такое MotionStack?

**Хронофотография** (motion stacking / sequence photography) — способ показать разные положения одного движущегося объекта на *одном изображении*.

MotionStack берёт **реальные кадры из исходного видео**, позволяет обвести нужного спортсмена на каждом кадре и объединяет выделенные фазы на одном фоне.

> **Здесь нет генерации искусственных людей и поз.** Если ребёнок подпрыгнул на скейте, приложение показывает именно то движение, которое было в записи, а не придуманное нейросетью.

**Возможности v0.2:**
- 🎬 Локальный выбор видео из памяти устройства.
- ⏱️ Настройка начала и конца интервала с точностью до десятых долей секунды.
- 🧩 Извлечение от **2 до 15** настоящих кадров (изображение строится с помощью системного видеодекодера).
- ✨ **Автоматическое выделение касанием:** нажми на торс спортсмена на одном кадре — MediaPipe MagicTouch определит маску объекта.
- 🏃 **Автоматическая обработка фаз:** позиция касания отслеживается по соседним кадрам, и модель рассчитывает новую маску на каждом.
- 🧠 AI-модель **встроена в APK** — работает без интернета.
- ✍️ **Ручная обводка** остаётся как запасной вариант, если автоматическая маска ошиблась.
- 🔎 Увеличение до 7× и перемещение изображения для более точной обводки.
- 🖼️ Выбор фонового кадра или **автофон** (медиана трёх кадров для подавления движущихся объектов).
- ✂️ **Полноразмерная альфа-маска** вместо прямоугольных вырезок, с мягким краем.
- 💾 Экспорт готовой композиции в **PNG**.
- 🔒 Работа **без сети и без загрузки видео на сервер**.

## 📱 Сборка и установка APK (без компьютера)

Благодаря **GitHub Actions** Android SDK, Gradle и Java на телефоне **не нужны**.

1. Перейди на страницу [**Build MotionStack APK**](https://github.com/Jagernau/motionstack/actions/workflows/build-apk.yml).
2. Нажми **Run workflow** → выбери `main` → ещё раз **Run workflow**. При изменениях в коде workflow также запускается автоматически.
3. Открой завершившийся запуск (🟢 зелёная галочка).
4. Пролистай до **Artifacts** и скачай архив **MotionStack-debug-APK**.
5. Распакуй архив на Android и установи файл `app-debug.apk`. При необходимости разреши установку из выбранного источника.
6. Запусти **MotionStack** — Termux и интернет для обработки **не требуются**.

⚠️ **Автоматическая модель ещё не проверена на реальном Android-устройстве.** Это debug-сборка для личного тестирования, а не подписанный релиз Google Play. Если workflow красный, открой журнал ошибочного шага — там будет конкретная причина.

## 🎯 Сделать фото трюка в два действия

1. Выбери MP4, интервал **0–1,5 секунды**, количество фаз **5–8**, нажми **«Извлечь реальные кадры»**.
2. Выбери фазу, где дочь хорошо видна. Переключи режим **«✨ Выбрать касанием (AI)»** и **коснись центра её туловища**. MotionStack обработает все фазы автоматически.

Результат появится внизу. Проверь все кадры и сохрани **PNG**.

**Если маска неверная:** уменьши область анализа («Уже»), выбери другой кадр, нажми на торс повторно. При необходимости используй ручную обводку конкретной фазы. На видео с несколькими людьми рядом автоматическое отслеживание может перейти на другого человека — это ограничение версии, которое нужно учитывать.

**Важно:** в узкой области анализа могут обрезаться руки или доска; выбери «Шире». Нейросеть не всегда выделяет скейтборд вместе с человеком, поскольку это отдельный предмет. Ручная корректировка пока только через полную обводку нужной фазы.

**Автофон:** выбирай «✨ Автофон» в выпадающем списке. Он объединяет фон из трёх настоящих кадров; на видео с движущейся камерой возможны артефакты.

Режим автоматического выделения есть **только в Android APK версии 0.2 и выше**. При запуске HTML через Termux работает ручная обводка; Python-сервер не содержит AI-модель.


## 🐍 Альтернатива — запуск через Python и Termux

Для отладки или работы без APK доступен локальный веб-интерфейс. Python нужен **только** для запуска HTTP-сервера; обработку выполняет браузер.

Установи [Termux из F-Droid](https://f-droid.org/packages/com.termux/), затем:

```bash
pkg update && pkg upgrade
pkg install python git
git clone https://github.com/Jagernau/motionstack.git
cd motionstack
python app.py
```

Открой в браузере телефона **http://127.0.0.1:8787**.

Никаких обязательных `pip install`, OpenCV или FFmpeg нет.

## 🧱 Технологии и архитектура

| Компонент | Используется для |
|---|---|
| HTML / CSS / JavaScript | Сенсорный интерфейс |
| HTML Canvas 2D | Обводка, выделение фазы, альфа-композитинг и автофон |
| MediaPipe MagicTouch (Android) | Сегментация по точке на самом телефоне |
| HTML Video | Декодирование видеоролика и выбор кадров |
| Android Java + WebView | Офлайн-оболочка приложения |
| Android Storage Access Framework | Выбор исходного видео и сохранение PNG |
| Python 3 (stdlib) | Необязательный HTTP-сервер для Termux |
| Gradle / GitHub Actions | Автоматическая сборка APK |

### Структура проекта

```text
motionstack/
├── .github/workflows/build-apk.yml  # сборка APK на GitHub
├── android/
│   ├── app/
│   │   ├── build.gradle
│   │   └── src/main/
│   │       ├── AndroidManifest.xml
│   │       └── java/dev/motionstack/app/MainActivity.java
│   ├── build.gradle
│   ├── settings.gradle
│   └── gradle.properties
├── autosegment.js                    # алгоритм автосегментации и трекер
├── app.py                            # Termux/desktop HTTP-сервер
├── index.html                        # весь графический интерфейс и алгоритм
├── .gitignore
└── README.md
```

**Важно:** один и тот же `index.html` работает в браузере и в APK (AI-функции доступны только через Android NativeBridge). Workflow перед компиляцией копирует его в Android `assets`. Поэтому интерфейс обновляется в одном месте. JavaScript `autosegment.js` также встраивается в APK при сборке.

## 🔐 Конфиденциальность

- Видео открывается из файлового хранилища **локально**.
- Кадры и маски обрабатываются на устройстве.
- В Android-приложении не запрашивается разрешение на доступ к интернету: модель MagicTouch скачивается **только GitHub Actions на этапе сборки** и встраивается в APK.
- Публиковать личные видео, особенно записи детей, в репозитории **не требуется**.

## ⚠️ Ограничения v0.1

| Что | Текущее состояние |
|---|---|
| Выделение человека | **Автоматическая маска MagicTouch по одному нажатию** с ручным резервным режимом |
| Автоматическая сегментация AI | В APK: MagicTouch; точность зависит от масштаба, освещения, других людей и перекрытий |
| Отслеживание человека | Простейшее сопоставление цветовых участков между кадрами; при быстром движении может ошибиться |
| Стабилизация камеры | Ещё нет |
| Удаление человека с фонового кадра | Медиана 3 кадров (приближённо), не гарантирует чистый фон |
| Поддержка видеоформатов | Зависит от декодера Android WebView / браузера |
| Слияние перекрывающихся силуэтов | Последние слои перекрывают предыдущие |
| Звуковая дорожка | Не используется |
| Сборка для Google Play | Ещё нет (только debug APK) |

Если человек уже виден на выбранном фоновом кадре, он останется и в итоговом изображении. Это **ограничение текущей реализации**, а не особенность хронофотографии в целом.
