## Зачем это приложение?

Снял трюк на скейте, BMX, роликах, футбэге или прыжок и хочешь показать **несколько положений спортсмена в одном кадре**, как на настоящей хронофотографии?

MotionStack берёт **реальное видео** и накладывает выбранные фазы на общий фон. Он **не дорисовывает** несуществующие движения и не генерирует других людей.

## ✨ Что нового в Studio 0.3

| Возможность | Что изменилось |
|---|---|
| 🎬 **Видеоплеер** | Просмотр исходного видео до обработки |
| 🎚️ **Видимый интервал** | Кинолента, границы начала/конца, повтор выделенного фрагмента и установка границ по текущему кадру |
| 🧩 **Подбор фаз** | Извлечение 12/18/24 кандидатов; выбор отличающихся положений **вместо равномерного наложения всех кадров** |
| ✨ **Нажатие на спортсмена** | MagicTouch сегментирует объект по касанию; следующие кадры обрабатываются с отслеживанием выбранной точки |
| 🛡️ **Проверка масок** | Проверка размера, скачков положения, цвета в области туловища, области кадра и формы маски; подозрительные кадры не добавляются автоматически |
| 🛹 **Скейтборд отдельно** | На выбранной фазе можно нажать «Добавить доску» и указать на скейт |
| 🧱 **Стабилизация** | Экспериментальная компенсация небольших **сдвигов** камеры (не вращения или сильного движения) |
| 🧽 **Очистка фона** | Для области выделенного спортсмена берутся пиксели других реальных кадров, где маска отсутствует |
| ✂️ **Кадрирование** | Вся сцена, зона трюка либо вертикальное 4:5 |
| 💾 **PNG** | Результат сохраняется на телефон, без интернета и удалённого сервера |

> **Это бета-версия.** Точность автоматической сегментации на маленьком человеке, за колонной и среди других детей не гарантирована. Некорректные фазы следует отключать. Отсутствующие в записи части тела не восстанавливаются.

## 📱 Установка с телефона

1. Открой [**MotionStack v0.3.0 — Releases**](https://github.com/Jagernau/motionstack/releases/tag/v0.3.0).
2. В **Assets** нажми `MotionStack-v0.3.0-debug.apk`.
3. Если Android не разрешает установку из этого источника, включи разрешение в системном диалоге.
4. Если обновление старой debug-версии не проходит из-за подписи, удали старое приложение и поставь новое.

Android 7.0+ (minSdk 24). Python и Termux для установленного APK **не требуются**.

## 🎯 Как получить хорошее фото

**1. Выбери видео.** Плеер откроет его на первом кадре. Передвигай ползунки «Начало»/«Конец» и смотри жёлтую область на киноленте. Можно воспроизводить отрезок по кругу. Для короткого трюка начни с 0–1,5 секунды.

**2. Извлеки кадры.** Начни с **4 желаемых фаз, 18 кандидатов, стандартного качества**. Повышай до 24 кандидатов, если движение слишком быстрое.

**3. Нажми на спортсмена.** Выбери кадр, на котором человека хорошо видно, и нажми по центру туловища. Модель MagicTouch работает прямо в Android APK; последующие кадры анализируются последовательно.

**4. Проверь маски.** На миниатюрах видно, какие фазы включены. Красный/восклицательный знак — сомнительный результат. Открой фазу и нажми на человека повторно. Для доски используй «Добавить доску». Кнопкой «Подобрать лучшие фазы» убери почти одинаковые положения.

**5. Настрой итог.** Попробуй «Очистить по всем кадрам» и «Крупно: зона трюка». Если фон выглядит странно — переключись на первый или последний кадр. Сохрани PNG.

**Съёмка:** неподвижная камера, больше расстояния от других спортсменов и крупный человек в кадре дадут заметно более надёжный результат. При существенном перекрытии колонной идеального силуэта алгоритм не получит.

## 🧠 Как работает алгоритм

```text
Видео MP4
   │
   ├── Плеер + временная шкала (начала и конца)
   │
   ▼
12–24 настоящих кандидатов + лёгкая стабилизация
   │
   ▼
Нажатие на человека → встроенная MagicTouch
   │
   ▼
Поиск точки в соседних кадрах + новая AI-маска каждого кадра
   │
   ├── Проверка размера, скачков и внешнего вида маски
   │
   └── Неуверенные кадры НЕ попадают в композицию
   │
   ▼
Подбор неповторяющихся положений (дистанция + перекрытие)
   │
   ▼
Восстановление фона из незакрытых областей настоящих кадров
   │
   ▼
Реальные силуэты + кадрирование → PNG
```

Трекинг реализован локальным сопоставлением участков изображения с проверкой каждой новой маски. Это **не SAM 2** и не гарантирует идентичность человека при сильных перекрытиях.

### Конфиденциальность

Все видео остаются на телефоне. В Android-приложении нет разрешения `INTERNET`. При GitHub Actions модель скачивается **во время сборки**, затем хранится внутри APK.

## 🛠️ Разработка

Проект — Android Java WebView, HTML/CSS/JavaScript Canvas, MediaPipe Tasks Vision (MagicTouch), Gradle. Python нужен только для необязательного локального сервера Termux.

```text
motionstack/
├── index.html
├── studio.js                  # видеоредактор и композиция
├── autosegment.js             # устаревший файл v0.2; не загружается в Studio
├── app.py                     # локальный запуск из Termux
├── android/                   # Android WebView + MagicTouch
├── tests/
│   ├── check_js.py            # блокирует сборку при ошибках JS
│   └── smoke_test.py          # локальный браузерный тест на выбранном MP4
└── .github/workflows/build-apk.yml
```

### Проверки

```bash
python3 tests/check_js.py
```

Дополнительный интеграционный тест (требует Python Playwright и установленный Chromium):

```bash
python3 tests/smoke_test.py /path/to/your/video.mp4
```

Тест браузера имитирует ответы нейросети. **Он не доказывает качество MagicTouch на реальном Android.** После сборки APK требуется проверка на устройстве.

### Запуск через Termux (без AI)

```bash
pkg install git python
git clone https://github.com/Jagernau/motionstack.git
cd motionstack
python app.py
```

Открой `http://127.0.0.1:8787`. Точный видеоредактор работает, но AI-сегментация требует нативного Android APK.

## ⚠️ Известные ограничения

- MagicTouch — **сегментация изображения по касанию**, а не нейросеть видеотрекинга с долговременной памятью. В толпе возможен переход на другого человека.
- «Добавить доску» нужно выполнять на нужных кадрах, если модель не захватила скейт вместе со спортсменом.
- Очистка фона зависит от наличия других кадров, в которых место за человеком видно. Нельзя восстановить закрытое на всех кадрах.
- Небольшие сдвиги камеры компенсируются; сильное панорамирование, вращение и изменение масштаба — нет.
- Итоговое разрешение ограничено исходником и выбранным качеством обработки. При далёкой съёмке детали не появятся от увеличения.
- Debug APK для тестов; релиз Play Store пока не планируется.
